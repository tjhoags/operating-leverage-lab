# Operating Leverage Lab

**Status: in development.** This repository currently contains project guidance only. There is no implemented application, verified calculation engine or published demonstration yet.

The intended tool compares the economics of an existing workflow with a proposed change. It should make cash expenses, human capacity, potential avoided hiring and implementation costs understandable without treating them as interchangeable savings.

The application architecture, interface, supported calculations and running instructions will be documented when implemented and verified. Examples will use synthetic data. No account connections or private records are included in this starter.
